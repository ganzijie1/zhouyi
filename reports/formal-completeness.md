# 形式完备性报告

## 有限结构证书

`proof-certificate.json` 记录 12 条版本化命题，覆盖 `B6`、`B3×B3`、`Q6`、Hamming/BFS、Klein 作用、互卦、变爻 XOR、文王序、上下卦矩阵与爻位谓词。B6 分配律在 262,144 个三元组上全域评估，Q6 最短路与 Hamming 距离在 4,096 个有序点对上全域评估；每条记录求值器哈希、论域、公理、边界、完整失败计数、反例样本和结果哈希。

## 形式背景与证据

- FCA：1,132 对象、5 个固定属性、1,454 关联、18 个概念，`complete=true`、`truncated=false`。
- 证据图谱：1,622 节点、6,681 条有类型边；含来源、篇章、卦、爻、段落、规则、证明、派生产物和可见结论；悬空引用 0，段落来源可达率 100%，每项声明的必需证据覆盖率 100%。
- 公理依赖：循环 0、缺失依赖 0、无根结论 0。
- 关卡模型：12 关均在明确有限状态域内穷举可达轨迹，最短解、预算失败和会话不变式与真实实现一致。

## 复现与边界

`npm run generate:formal` 重建派生 JSON，`npm run validate:formal` 校验真实源码/公理/语料输入哈希、证书字节一致、FCA 完整和图谱闭合。上述结果只证明固定源码、固定语料、显式公理和有限输入域中的命题；不证明经典具有唯一语义、作者原意可计算、占筮有效或预测成立。
